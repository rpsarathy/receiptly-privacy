# Receiptly.ai — legal

The published privacy policy for the Receiptly.ai iOS app.

`index.md` is the page served at the GitHub Pages URL, and that URL is the
one registered in App Store Connect. Apple requires it to stay reachable for
as long as the app is on the store, so this repository is not a scratch space.

The source of truth is `PRIVACY.md` in the app repository, where the policy
sits beside the code that makes it true. Change it there first, then copy it
here — a policy that drifts from the build is worse than none.
